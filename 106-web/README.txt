TARUN - JAVA PROGRAMMING VIRTUAL RECORD

This static website follows the black/navy background, neon-lime accent, dark program cards, top navigation and three-column weekly grid shown in Tarun's supplied screenshots.

Includes weeks 10, 11 and 12 (42 programs total) with question, Java code and expected output. Existing supplied records/weeks are retained from the working project bundle.

Run: open index.html with VS Code Live Server.
Profile image: optionally place the image at assets/profile.png.
Deployment: upload index.html, style.css, script.js, README.txt and assets to the tarun-web repository root.
